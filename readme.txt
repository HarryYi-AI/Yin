方法一：传统机器学习方法 (TF-IDF + 逻辑回归)
文本清洗： 去除 HTML 标签、非字母字符，转换为小写。
文本预处理： 分词，去除停用词（如 "the", "a", "is" 等常见但信息量少的词）。
特征提取： 使用 TF-IDF 将处理后的文本转换为数值特征向量。
模型训练： 使用逻辑回归模型在训练数据上进行训练。
模型评估： 在测试数据上评估模型性能（准确率、分类报告）。
可视化： 生成词云图展示最常见的词语，绘制条形图展示情感标签的分布。
方法二：深度学习方法 (BERT)
环境设置： 安装 Transformers 和 PyTorch 库。
数据准备： 重新加载数据（或复用），将标签映射为 0/1，划分训练集和验证集。
BERT Tokenizer： 加载预训练的 BERT Tokenizer，用于将文本转换为 BERT 模型能理解的格式（包括特殊标记、词汇表映射、padding、truncation）。
数据编码： 定义函数将文本和标签编码为模型输入格式（input_ids, attention_mask 等）和 PyTorch 张量。
创建 PyTorch Dataset： 定义一个自定义的 Dataset 类，方便 DataLoader 加载数据。
加载预训练 BERT 模型： 加载 bert-base-uncased 模型，并指定用于二分类任务 (num_labels=2)。
设置优化器和学习率调度器： 使用 AdamW 优化器和线性学习率调度器。
创建 DataLoader： 为训练集和验证集创建 DataLoader，用于批量加载数据。
设备设置： 自动选择使用 GPU（如果可用）或 CPU。
训练循环：
设置模型为训练模式。
迭代指定的 epoch 次数。
在每个 epoch 中，迭代 DataLoader 提供的每个 batch。
将数据移到指定设备（GPU/CPU）。
执行模型的前向传播，计算损失。
执行反向传播，计算梯度。
更新模型参数（优化器）。
更新学习率（调度器）。
使用 tqdm 显示进度条和损失。
评估循环：
设置模型为评估模式（关闭 dropout 等）。
关闭梯度计算 (torch.no_grad())。
迭代验证集的 DataLoader。
获取模型预测结果。
收集所有预测结果和真实标签。
性能评估： 计算验证集上的准确率和详细的分类报告。
模型保存： 将训练好的模型和对应的 Tokenizer 保存到本地。
